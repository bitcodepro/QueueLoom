The RabbitMQ witness selects body B but the baseline acknowledges body A, both with the same application MessageId, and reports the selection deleted. Selecting both also collapses the request. Selected deletion now fails closed before acquisition, backup or settlement. Immediate, scheduled and durable Move are blocked before sending; the UI and provider topology expose that restriction, and MCP reports it. Copy and backed-up source purge retain their existing confirmation boundaries. No synthetic hash or AMQP delivery tag is promoted to a durable broker identity. Broker coverage additionally performs a body search for B and verifies both deliveries remain, no replacement was sent, and no selected-delete backup was produced.

History reads and updates now acquire the existing cross-process file lock and reload the current disk snapshot. Compaction uses the existing durable atomic writer. Appending preserves a crash tail, adds its missing line separator, and flushes the completed new sample. Independent fixture processes both load the stale baseline before the first process appends/compacts; both successful samples survive reopening after the second process appends/compacts. Ordinary terminated lines, empty tails and a valid final record without a newline are controls.

Azure receive failures preserve earlier successful completion results, report only the unfinished selection Failed, and release unselected locks. Timeout-shaped cancellation without caller cancellation follows that failure path; genuine caller cancellation remains Cancelled. The regression checks the actual completed source, its backup, released locks and item results.

Updater cleanup preserves the original marker while any payload remains. After payload removal it publishes an ID-bound, flushed cleanup proof beside the receipt before removing the final marker. A restart can remove a markerless directory only when that proof matches and the directory is empty. Foreign proof, foreign files and missing ownership remain blocked; a locked receipt retains the cleanup proof for retry. The old fixed-delay test assertion remains intact. The new locked-archive regression compares the marker's original timestamp, proving it was not deleted and recreated.
